# Zelfvoorstelling (Dutch Self‑Introduction)

## Overview

This short text is a simple self‑introduction in Dutch. It helps you present yourself with basic sentences and easy vocabulary.

---

## Self Introduction Example

Hallo, ik ben Emma. Ik ben 25 jaar oud.
Ik woon in Thuin, dichtbij Binche.
Ik heb informatica gestudeerd in Namur.
Ik werk al meer dan vier jaar bij AG Insurance als informaticus.
Ik heb drie jaar in een webteam gewerkt. Nu werk ik in een backend‑team.
Ik speel tafeltennis sinds 2011.
Ik ga één tot twee keer per week naar de fitness.
Ik hou van videogames en sociale media.
