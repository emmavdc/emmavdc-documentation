# Essential Web Concepts

This document gives a short and simple overview of important web concepts.
It applies to both websites and APIs.

The goal is to understand the basics of how the web works before going into technical details.

---

## Authentication

Authentication is the process of checking who you are.

It answers the question: **"Who are you?"**

On the web, authentication can be done using:
- Cookies
- Tokens (JWT, OAuth2, OpenID Connect)
- API keys

Authentication is often used for:
- User login on websites
- Securing access to APIs

---

## Authorization

Authorization defines what an authenticated user is allowed to do.

It answers the question: **"What are you allowed to do?"**

Examples:
- Access to private pages
- Restricted actions (admin, editor, user)
- Permissions based on rules

---

## CORS (Cross-Origin Resource Sharing)

CORS is a security mechanism used by web browsers.

It controls how a website can make requests to another domain.

By default, browsers block requests to a different origin for security reasons.

The server must allow this using HTTP headers:
- Allowed origins
- Allowed HTTP methods
- Allowed headers

CORS is mainly a browser concept and does not apply to server-to-server calls.

---

## HTTP and the Web

The web is based on the HTTP protocol.

Clients (browsers, applications) send HTTP requests to servers.
Servers send HTTP responses back.

Common HTTP methods:
- `GET` to read data or pages
- `POST` to send data
- `PUT` / `PATCH` to update data
- `DELETE` to remove data

---

## Websites

A website is usually accessed through a web browser.

It can be:
- Static (HTML, CSS, JavaScript files)
- Dynamic (generated by a server)

Websites often use:
- Sessions and cookies
- Forms and navigation
- Client-side and server-side logic

---

## Web APIs

A web API allows applications to communicate over HTTP.

APIs are often used by:
- Websites (frontend calling a backend)
- Mobile applications
- Other services

APIs usually return data (often JSON) instead of HTML pages.
