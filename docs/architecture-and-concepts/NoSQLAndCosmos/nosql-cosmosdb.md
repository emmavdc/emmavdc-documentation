# NoSQL & Cosmos DB Concepts

---

## NoSQL — Quick Overview
NoSQL databases are non‑relational systems designed for flexibility and high scalability.  
They do not require a fixed schema and can handle large amounts of data with fast access.  
Common models include document, key‑value, column, and graph databases.

## Azure Cosmos DB — Quick Overview
Azure Cosmos DB is a fully managed NoSQL database service from Azure.  
It offers global distribution, low latency, and automatic scaling.  
It supports multiple APIs (SQL/Core, MongoDB, Cassandra, Gremlin, Table) and uses throughput (RU/s) for billing.
